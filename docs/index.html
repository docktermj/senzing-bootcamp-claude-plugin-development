Quick start

Senzing Bootcamp for Claude

From nothing installed to a running bootcamp, in Claude Desktop or the Claude Code CLI.

Get started

New to the bootcamp? Start at hub.senzing.com/bootcamp

Checklist

Before you start

  • Plan: at least a Claude Max 5x plan. A Claude Pro plan also works, across several 5-hour windows, but not in one session.
  • Network access to the Senzing MCP server (https://mcp.senzing.com/mcp). The bootcamp cannot proceed without it. On a corporate network or VPN, ask for the domain mcp.senzing.com to be allowed.
  • Python 3, available as python3 on the PATH. The bootcamp's hooks and its graduation recap run on it. On Windows, if only python or py is installed, add a python3 entry to the PATH.
  • A new, empty folder for the bootcamp.
  • Recommended A business problem and 5,000 to 20,000 records. A problem that needs entity resolution, and records that illustrate it. Recommended, not mandatory.
  • Claude Desktop only git installed. Claude Desktop requires it. Without it, the Add Marketplace icon (+) is missing and the plugin cannot be installed.

Install and start

Install the plugin and start the bootcamp

Choose one path. Both end with the bootcamp running in Claude Code.

  • Claude Desktop (no terminal)
  • Claude Code CLI

Claude Desktop

Claude Code inside the desktop application. No terminal needed.

  1. Download and install Claude Desktop.
  2. Start Claude Desktop.

    If asked, install git.

  3. Open a new Claude Code session:
    1. In the left-hand pane, choose </> Code.
    2. In the Code pane, click New.
  4. Near the bottom, choose the working directory (it might say Select folder...), and select your new, empty folder for the bootcamp.
  5. Install the Senzing Bootcamp plugin:
    1. On the bottom, click the Add icon (+).
    2. Click Add Plugins... (or it may be just Plugins).
    3. In the Directory pane, near Filter by and Sort by, click the Add Marketplace icon (+). If the plus sign is missing, see Troubleshooting.
    4. In the Add marketplace pane, for URL:, enter: 
      https://github.com/docktermj/senzing-bootcamp-claude-plugin-development
    5. Click Sync.
    6. In the Directory pane, select the Code tab.
    7. Select Senzing bootcamp.
    8. Click Install.
    9. Close the Directory pane.
  6. On the bottom, set the mode, model and effort:
    1. Choose the Mode auto for a smooth ride.
    2. Choose the Model Sonnet 5.
    3. Choose the Effort medium.
  7. Near the bottom, in the agentic chat, enter: 
    Start the bootcamp

    Or use the /start-bootcamp command. See Bootcamp commands for the rest.

Claude Code CLI

Claude Code in a terminal.

  1. Install the Claude Code CLI:

    macOS, Linux, or WSL

    curl -fsSL https://claude.ai/install.sh | bash

    Windows, in PowerShell

    irm https://claude.ai/install.ps1 | iex

    Windows is fully supported. If you would rather not use a terminal at all, Claude Desktop is the graphical route and works on Windows too.

  2. Add the Senzing Bootcamp marketplace: 
    claude plugin marketplace add docktermj/senzing-bootcamp-claude-plugin-development
  3. Install the Senzing Bootcamp Claude Plugin: 
    claude plugin install senzing-bootcamp@senzing-bootcamp-dev

    If the plugin is already installed, update it instead:

    claude plugin update senzing-bootcamp@senzing-bootcamp-dev
  4. Create a new directory for the bootcamp: 
    mkdir senzing-bootcamp
  5. Change into it: 
    cd senzing-bootcamp
  6. Start the Claude Code CLI on Sonnet 5 at medium effort, with --permission-mode auto for the smoothest ride: 
    claude --model claude-sonnet-5 --effort medium --permission-mode auto
  7. Start the bootcamp. Tell Claude: 
    Start the bootcamp

Claude Code for VS Code and other Claude Code clients also run the plugin. Install it the way your client installs plugins, then start the bootcamp the same way.

What happens next

The bootcamp first asks you to choose your curriculum, level of detail, and programming language, then guides you module by module. See every module

Good to know

Tips

Model and effort

Sonnet 5 at medium effort for most modules. At the start of each module the bootcamp tells you when to switch to Opus 5.

Bootcamp commands

The plugin ships these slash commands. Each also works as plain English, so you never have to remember them.

CommandWhat it does
/start-bootcampStart the bootcamp, or resume one already in progress (same as saying “Start the bootcamp”).
/bootcamp-feedbackShare feedback about the bootcamp at any time (same as saying “bootcamp feedback”). Saved locally to docs/feedback/SENZING_BOOTCAMP_PLUGIN_FEEDBACK.md.
/graduateGraduate: render the recap PDF and generate the production/ starter project. Bootcamp graduation normally follows the last module on its own, so use this only to graduate early or to re-run it.
/bootcamp-noteJot down an idea, question, reminder or to-do at any time (same as saying “make a note”). Saved locally to docs/bootcamp_notes.md and folded into your recap at graduation.
/package-bootcampPackage your bootcamp into a single zip under backups/packages/ (same as saying “back up the bootcamp”) — either the results to share, or everything needed to continue on another machine. Written locally; nothing is sent anywhere.

Update or uninstall

Update the plugin:

claude plugin update senzing-bootcamp@senzing-bootcamp-dev

Uninstall the plugin:

claude plugin uninstall senzing-bootcamp@senzing-bootcamp-dev

Remove the marketplace:

claude plugin marketplace remove senzing-bootcamp-dev

If something goes wrong

Troubleshooting

Claude Desktop won’t take prompts, or the Add Marketplace + is missing

The Claude Desktop installation may be incomplete. Claude Desktop requires git: install git, then restart Claude Desktop.
